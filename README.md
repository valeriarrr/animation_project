## Описание проекта

Программа представляет собой интерактивную доску, в которой пользователь щелчком мыши может устанавливать или снимать значения нескольких двоичных регистров (менять 0 на 1 или 1 на 0). Программа считывает значение получаемого двоичного числа, может отображать внутри
каждого регистра его цифровое
значение и имеет также другие системы счисления (троичную
уравновешенную, систему со
смешанным основанием).

## Функциональные возможности

### Основной функционал
- ✏️ Смена значений двоичных регистров
- 📊 Пересчет конечного значения
- 💾 Вывод конечного значения

### Дополнительный функционал
- 🎨 Отображение цифрового значения каждого регистра внутри него
- ➕ Пересчет значений других систем счисления
